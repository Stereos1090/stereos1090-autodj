# Stereos 1090 - AutoDJ Engine (Hi-Fi)

Motor de automatización y procesamiento de audio 24/7 para la estación **Stereos 1090** (`stereos1090.com`).

## Arquitectura
- **Motor:** Liquidsoap v2.1.4 con compresión de audio y limitador maestro.
- **Calidad:** Transmisión estéreo de alta fidelidad a 320 kbps.
- **Almacenamiento:** Sincronizado con Cloudflare R2 (`stereos1090-live`).
